# GDPR & Cookie Compliance Automation

## Overview

This project automates the generation of GDPR and Cookie compliance documents for websites, surveys, and other interactive activities. Users submit answers to structured questions and can immediately download free, watermarked documents or pay for premium copies without the watermark.

The backend is implemented in **Go (Golang)** using only the standard library so it can be compiled and executed in restricted environments (such as air‑gapped compliance networks). Documents, payments and transaction history are persisted in a compact JSON file, making the system portable and easy to audit.

This system can also be used for rapid development of any document generation workflow that follows a question/answer flow.

---

## Features

- **Automated GDPR & Cookie policy generation** via REST endpoints
- **Built-in templates** with metadata and field definitions for dynamic forms
- **Watermarked vs. premium downloads** handled automatically by the API
- **Local balance tracking and payment history** stored in the JSON datastore
- **Configuration via environment variables or JSON file** with sensible defaults
- **Zero external dependencies** – builds with stock Go toolchain only

## Tech Stack

### Backend:
- **Go (Golang)** – Core application logic and HTTP server

### Persistence:
- **JSON storage** – Single file (`data/app.json`) that stores documents, account balance and payment history

## Installation & Setup

### 1. Clone the Repository
```sh
git clone https://github.com/axshaman/law_for_it.git
cd law_for_it
```

### 2. Configure the Application
The server runs with sensible defaults out of the box. Configuration can be supplied via:

- **Environment variables** (e.g. `SERVER_PORT=9090 go run main.go`)
- **A JSON configuration file** (copy `config.example.json` to `config.json` and adjust the values)

```json
{
  "server": {
    "host": "0.0.0.0",
    "port": 8080
  },
  "database": {
    "path": "data/app.json"
  },
  "document": {
    "formats": ["pdf", "docx"],
    "watermark": "Generated by law_for_it",
    "premium_price": 19.99
  },
  "payment": {
    "currency": "EUR"
  }
}
```

Launch the service with:

```sh
go run ./...
```

## Document Templating System

The server ships with two built-in templates (`gdpr_basic` and `cookie_standard`). Each template declares:

1. **Metadata** – name, display name, description and tags.
2. **Fields** – the form inputs expected from the caller.
3. **Content** – a Markdown-like text template rendered with Go's `text/template` engine. Placeholders use the `{{.field_name}}` syntax.

The `/templates` endpoint exposes the full schema so client applications (web forms, chat bots, CLI tools) can render dynamic questionnaires without hard-coding the fields.

---

## Payment System

- Free users can download **watermarked** documents.
- **Premium users** are charged (from the local balance) and receive watermark-free documents.
- The balance, currency and transaction history are stored locally in the JSON database so auditors can inspect every change.
- Use the `/topup` endpoint to increase the balance and `/payhistory` to inspect transactions.

## Usage

### Example API Flow

1. List templates: `GET /templates`
2. Submit answers: `POST /generate` with JSON payload
3. Download the free document: `GET /downloadf/{id}`
4. (Optional) Top up balance: `POST /topup`
5. Request a premium document by setting `"premium": true` when calling `/generate`

---

## API Endpoints
| Method | Endpoint         | Description                    |
|--------|-----------------|--------------------------------|
| GET    | `/status`       | Health check                   |
| POST   | `/generate`     | Generate a GDPR/Cookie policy  |
| GET    | `/downloadf/:id`| Download generated document    |
| GET    | `/downloadp/:id`| Download full document         |
| GET    | `/balance`      | Get user balance               |
| GET    | `/payhistory`   | Get billing's history          |
| POST   | `/topup`        | Top up user balance            |
